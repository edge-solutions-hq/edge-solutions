## 🔥 Branding Research & Design Prompt (Professional / Tech / WebGL-Ready)

> **Role & Context**
> You are a **senior brand strategist + digital designer** specialized in **tech, software agencies, and high-end digital products**.
> You are tasked with creating a **clear, professional, conversion-oriented brand identity** for a **personal/company website** that offers **two distinct but related services**:
>
> 1. **Web Development Services**
>    (PHP, Laravel, WordPress, Next.js, React, Vue, modern web stacks)
>
> 2. **Real-Time / Game / WebGL-oriented Technologies**
>    (real-time systems, interactive experiences, WebGL, possibly game tech)
>
> The website must **not confuse the two services**, but show they belong to the same expert identity.

---

## 🎯 Objectives

* Convey **credibility, clarity, and senior expertise**
* Feel **modern, technical, clean, and confident**
* Be **conversion-oriented** (contact, quote requests)
* Work perfectly with:

  * **Tailwind CSS**
  * **Next.js / Vercel**
  * **Future WebGL / 3D / shader integrations**
* Avoid trendy/overdesigned aesthetics that age quickly

---

## 🧠 Brand Positioning

* Target audience:

  * SMEs, startups, founders, technical leads
  * Clients who value **quality, performance, maintainability**
* Tone:

  * Professional
  * Calm confidence
  * Technical but accessible
* Keywords:

  * Precision
  * Performance
  * Reliability
  * Engineering mindset
  * Modern craftsmanship

---

## 🧩 Deliverables Required

### 1️⃣ Visual Identity Foundations

Provide **clear, usable definitions**, not abstract ideas.

#### 🎨 Color System

* Primary brand color (with HEX)
* Secondary / accent colors (HEX)
* Neutral palette (backgrounds, text, borders)
* Dark mode compatibility
* Accessibility considerations (contrast)
* How colors should be used:

  * CTAs
  * Links
  * Highlights
  * WebGL / canvas overlays

---

### 2️⃣ Typography System

* Primary font (professional, readable, modern)
* Secondary font (optional)
* Font usage rules:

  * Headings (H1–H6)
  * Body text
  * UI labels
  * Code / technical accents (if relevant)
* Web-safe / Google Fonts preferred
* Should pair well with **Tailwind CSS**

---

### 3️⃣ Design Style & UI Guidelines

Define a **clear visual language**:

* Layout philosophy (spacing, density)
* Use of:

  * White space
  * Borders vs shadows
  * Cards vs flat sections
* Button styles
* Link styles
* Icon style recommendations
* Motion & micro-interaction guidelines (subtle, professional)

---

### 4️⃣ WebGL & Advanced Visuals Guidelines

Since WebGL will be added later, define **rules**, not implementations:

* How WebGL elements should integrate:

  * Hero sections
  * Backgrounds
  * Accents
* Visual constraints:

  * Subtlety vs spectacle
  * Performance considerations
* Color & contrast rules with 3D content
* When **not** to use WebGL

---

### 5️⃣ Brand Voice & Content Tone

* Writing tone:

  * Homepage
  * Services pages
  * CTAs
* Do’s and Don’ts
* Example micro-copy:

  * Buttons
  * Section headers
  * Contact prompts

---

### 6️⃣ Practical Output Format

* Provide:

  * Clear bullet points
  * Tables where relevant (colors, fonts)
  * Actionable rules (not vague concepts)
* This branding should be **directly usable by a developer/designer**
* Assume **no CMS**, content in **Markdown**

---

## 🚫 Explicitly Avoid

* Overly playful or “startup hype” branding
* Generic agency clichés
* Loud gradients everywhere
* Visuals that conflict with future WebGL layers
