# Documentation Map

This directory separates active project guidance from historical planning notes.

## Start Here

- `positioning.md` — primary source for website, design, and content decisions. This overrides older dual-service planning notes.
- `architecture.md` — active Module ownership map for the Next.js app.
- `design-baseline.md` — current visual baseline and design guardrails.
- `tech-stack.md` — stack choices, commands, and setup notes.

## Active Operational Docs

- `analytics/conversion-event-taxonomy.md` — runtime conversion event contract.
- `analytics/gtm-ga4-production-readiness.md` — analytics rollout checklist.
- `prd/` — PRDs and implementation planning records.
- `agents/` — issue tracker, triage label, and domain-doc configuration for agent skills.

## Archive

- `archive/initial-planning/` contains early research, prompts, drafts, and launch-planning notes.
- Archived docs are useful history, not current source of truth.
- If archived guidance conflicts with active docs, follow `positioning.md`, `architecture.md`, and `design-baseline.md`.

## Source-Of-Truth Order

1. `positioning.md`
2. `architecture.md`
3. `design-baseline.md`
4. `tech-stack.md`
5. Active operational docs under `analytics/`, `prd/`, and `agents/`
6. Archive docs for historical context only
