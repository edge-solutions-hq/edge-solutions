# Domain Docs

How engineering skills should consume this repo's domain documentation.

## Layout

This repo uses a single-context layout.

## Before Exploring

- Read `AGENTS.md` for agent-facing setup, checks, and working rules.
- Read `WEBSITE.md` for source-of-truth order and website operating constraints.
- If `CONTEXT.md`, `CONTEXT-MAP.md`, or `docs/adr/` are added later, read them before architecture, diagnosis, TDD, PRD, or issue work.

## Domain Language

Use `docs/positioning.md` for canonical positioning language. Do not redefine it here.

## ADR Conflicts

If output contradicts a future ADR, surface it explicitly and either justify reopening it or mark the relevant work blocked.
